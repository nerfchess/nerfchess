# Vault

Persistent project memory, in Obsidian-compatible markdown. Claude reads this at the start of tasks and writes durable knowledge back (see CLAUDE.md §7).

- `notes/` — one note per topic or decision, named `YYYY-MM-DD-topic.md`.
- Keep notes short and factual: what was decided, why, and links to PRs/files.
- This folder can be opened directly as an Obsidian vault, or synced into an existing one.
