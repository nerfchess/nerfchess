# Tier 8 buffs finished

Date: 2026-07-04. Branch claude/tier8-buffs. Completes the buff library work from PR #105 ([[2026-07-04-owner-feedback-round3]] listed tier 8 as outstanding).

All 14 previously stubbed tier 8 cards are now implemented and enter the draft pool via IMPLEMENTED_BUFFS. Most reuse the tier 7 helper factories (captureExplosion, bindPiece, voidSquares, relocateMany, shield/king_safe effects). Design decisions where the stub text was not directly implementable:

- **Perfect Rewind**: fixed depth instead of "any position": rewinds piece placement to eight half-moves ago (or to when it was drafted, if newer). It snapshots the board after every ply in instance state, so it replays deterministically online. Captured-piece counters are not rewound; revive pools can theoretically double-count, same class of quirk as Genesis.
- **Draft Supremacy**: redesigned to existing flags: you take both cards in your next draft and the opponent's next draft is skipped. Choosing the opponent's cards for them would have needed new protocol plus UI for one card.
- **Total Warp / Reality Warp**: relocateMany pairs; the king is excluded (relocateMany convention). Total Warp caps at 15 pairs = every non-king piece.
- **Immortal King / Checkmate Denial**: king_safe effect; the ActiveEffect type now allows turns: null (permanent) for king_safe. Immortal King's text spells out that you can still lose by running out of moves.
- **Endless Turn**: free action; after activation every non-capture move by the owner grants one more extra move, a capture spends the card. Only the owner's clock runs during the chain; chainKingGuard already blocks king-capture finishes.
- **Titan Legion**: first multi-piece bind (state.sqs); onlinePermanent already recognized state.sqs so nullify resistance works.
- **Genesis**: rebuilds the opening placement via api.place, clears all board effects, restores both sides' castling, resets the fifty-move counter, removes my nerf. Held buffs and drafts survive.

Verification: npm run typecheck clean; 34-assertion engine simulation (scratchpad tier8-sim.ts, not committed) covering every new card passed.
